## Portal draft

Title: FirstStep: a source-checked careers finder for your first developer role

Build URL: https://github.com/himanshu748/firststep-careers-finder

Description:

FirstStep finds developer internships and entry-level roles from public employer career pages. Set keywords, location, work arrangement, employment type, seniority and visa preferences, then choose up to five reviewed employers. Each run considers at most twenty candidates. Results keep source links, checked timestamps, requirements, literal keyword matches and unknown fields. A remote label never becomes an assumption that someone in India is eligible.

TinyFish Search discovers official career URLs, Agent navigates permitted public listings, and Fetch checks access rules and corroborates each source. Removing TinyFish stops live discovery, navigation and verification. The latest combined demo found an Affirm internship in San Francisco (hybrid) and a Cloudflare internship in Lisbon (on-site). Both were checked on 15 October 2026. It used seven provider requests and reported 16 and 9 Agent steps. It remains partial because the demo checked one candidate per employer.

FirstStep includes filters, browser-local saved jobs and formula-safe CSV export. Keys stay server-side. URL validation, a persistent request ledger, wallet safety checks and full Agent credit reservations bound the work to approved existing free credits. It never applies, uploads a resume, creates employer accounts or contacts anyone. No purchases or top-ups were made.

Validation: 51 core/CLI tests and five isolated browser tests pass. Fixtures are explicitly labeled and never seed production. The clean source archive installs locked dependencies, builds and passes local security checks. Earlier failures remain dated evidence. Seven employers are reviewed; live extraction evidence covers three across Agent and the optional Browser workflow. Maximum pagination is fixture-tested. This is a local single-user app; provider DNS, intermediate Fetch redirects and internal Agent navigation remain documented trust boundaries. No endpoint score or sponsor approval is claimed.

Evidence: [VERIFICATION.md](../evidence/VERIFICATION.md), `live-agent-combined-2026-10-15.json`, the two-row CSV, current UI captures and [DEMO.md](DEMO.md). The archive excludes credentials, account balances, private history, dependencies and compiled output.
